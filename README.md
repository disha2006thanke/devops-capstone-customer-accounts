# Customer Accounts Microservice

[![Build Status](https://github.com/disha2006thanke/devops-capstone-customer-accounts/actions/workflows/ci-build.yaml/badge.svg)](https://github.com/disha2006thanke/devops-capstone-customer-accounts/actions/workflows/ci-build.yaml)

## Project Name

Customer Accounts Microservice

## Description

A RESTful Customer Accounts microservice developed as part of the DevOps Capstone project.

The application provides REST APIs to create, read, list, update, and delete customer accounts.

## Technologies

- Python
- Flask
- REST API
- GitHub Actions
- Docker
- Kubernetes
- Tekton

## CI/CD

This project uses GitHub Actions for continuous integration, including code linting and automated testing.
